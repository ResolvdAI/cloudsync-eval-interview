# CloudSync Frequently Asked Questions

## General Questions

### What is CloudSync?
CloudSync is a cloud-based file synchronization and backup service that keeps your files safe, synchronized, and accessible from anywhere. It automatically backs up your important files and allows you to access them from any device.

### How does CloudSync work?
CloudSync creates a special folder on your computer. Any files you place in this folder are automatically uploaded to our secure cloud servers and synchronized across all your connected devices. Changes made on one device are instantly reflected on all others.

### Is CloudSync secure?
Yes, CloudSync uses industry-standard encryption:
- 256-bit AES encryption for files at rest
- TLS 1.3 encryption for files in transit
- Two-factor authentication available
- SOC 2 Type II certified data centers
- GDPR compliant

### What platforms does CloudSync support?
CloudSync is available on:
- Windows (10 and 11)
- macOS (10.15 and later)
- Linux (Ubuntu, Fedora, Debian)
- iOS (14.0 and later)
- Android (8.0 and later)
- Web browser access

## Account & Billing

### How do I create an account?
1. Visit www.cloudsync.com
2. Click "Sign Up"
3. Enter your email and create a password
4. Verify your email address
5. Choose your plan

### What payment methods do you accept?
We accept:
- Credit cards (Visa, MasterCard, American Express)
- Debit cards
- PayPal
- Bank transfers (Enterprise plans only)
- Annual invoicing (Enterprise plans only)

### Can I change my plan?
Yes, you can upgrade or downgrade your plan at any time:
- Upgrades take effect immediately
- Downgrades take effect at the next billing cycle
- No penalties for plan changes
- Prorated billing for upgrades

### How do I cancel my subscription?
To cancel your subscription:
1. Log into your account
2. Go to Settings > Billing
3. Click "Cancel Subscription"
4. Follow the confirmation steps
Your files remain accessible until the end of your billing period.

### Is there a free trial?
Yes, we offer:
- 14-day free trial for all paid plans
- No credit card required for trial
- Full feature access during trial
- Automatic conversion to free plan if not upgraded

## Storage & Files

### How much storage do I get?
Storage by plan:
- Free: 5GB
- Basic: 100GB
- Professional: 2TB
- Enterprise: Unlimited

### What file types can I store?
CloudSync supports all file types with no restrictions. However, certain files may not preview in the web interface.

### Is there a file size limit?
- Free plan: 100MB per file
- Basic plan: 5GB per file
- Professional plan: 50GB per file
- Enterprise plan: No limit

### How do I free up storage space?
To free up space:
1. Delete unnecessary files
2. Empty the trash (deleted files stay in trash for 30 days)
3. Remove old file versions
4. Check for duplicate files
5. Upgrade your plan for more storage

### Can I recover deleted files?
Yes, deleted files are kept in the trash for:
- Free plan: 30 days
- Paid plans: 90 days
- Can be restored anytime within this period
- Permanently deleted after the retention period

## Sharing & Collaboration

### How do I share files?
To share files:
1. Right-click on the file or folder
2. Select "Share"
3. Choose sharing method:
   - Email invitation
   - Copy shareable link
   - Add collaborators directly

### Can I set permissions for shared files?
Yes, you can set:
- View only
- Can comment
- Can edit
- Can delete (folder owner only)
- Expiration dates for shared links

### How many people can I share with?
- Free plan: Up to 3 collaborators
- Basic plan: Up to 10 collaborators
- Professional plan: Up to 50 collaborators
- Enterprise plan: Unlimited

## Technical Issues

### Why isn't my file syncing?
Common causes:
- No internet connection
- CloudSync app not running
- Storage quota exceeded
- File in use by another program
- Sync paused manually
- Filename contains invalid characters

### How do I resolve sync conflicts?
When a conflict occurs:
1. CloudSync creates copies of both versions
2. Review both versions
3. Choose which to keep
4. Delete the unwanted version
5. Sync continues normally

### Why is sync slow?
Factors affecting sync speed:
- Internet connection speed
- File size and number
- Server load
- Antivirus software scanning
- Other apps using bandwidth

### What are the system requirements?
Minimum requirements:
- 2GB RAM
- 200MB disk space for app
- Broadband internet connection
- 64-bit operating system

## Mobile Apps

### How do I set up the mobile app?
1. Download from App Store or Google Play
2. Open the app
3. Sign in with your CloudSync credentials
4. Grant necessary permissions
5. Choose folders to sync

### Can I upload photos automatically?
Yes, enable Camera Upload to:
- Automatically backup photos
- Backup videos (optional)
- WiFi-only upload option
- Background upload support

### Can I access files offline?
Yes, you can:
- Mark files for offline access
- Automatically sync recent files
- Manage offline storage limits
- Sync when connection returns
